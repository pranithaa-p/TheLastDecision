# The Last Decision

### An Interactive Experience Inspired by Thirukkural 461

**The Last Decision** is a web-based interactive game inspired by **Thirukkural 461**, where players experience the importance of thoughtful decision-making through exploration, choices, and consequences.

Set in **Chennai 2047**, the player navigates a city facing a critical power crisis. Decisions made throughout the game affect different sectors of the city, requiring the player to gather information, evaluate consequences, and make a final allocation decision.

## Thirukkural 461

> **அழிவதூஉம் ஆவதூஉம் ஆகி வழிபயக்கும்**  
> **ஊதியமும் சூழ்ந்து செயல்.**

**Meaning:**  
Before undertaking an action, consider what may be lost, what may result, and what lasting consequences may follow.

The game translates this idea into an interactive decision-making experience rather than presenting the Kural as static text.

## Key Features

- Interactive narrative set in **Chennai 2047**
- Exploration-based gameplay
- NPC conversations and information gathering
- Decision-making with visible consequences
- Dynamic city state based on player choices
- Final resource allocation challenge
- Multiple possible outcomes
- Interactive discovery of the Kural's key ideas
- Responsive desktop and mobile controls
- Colourful, cartoon-inspired environment

## Controls

| Control | Action |
|---|---|
| `W` / `↑` | Move Up |
| `A` / `←` | Move Left |
| `S` / `↓` | Move Down |
| `D` / `→` | Move Right |
| `E` | Interact |
| `Space` / `Enter` | Continue / Interact |

Mobile users can use the on-screen controls.

## Running the Project

No installation or backend setup is required.

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a browser.

For development, the project can also be run using a local server such as **VS Code Live Server**.
